# UFO WASH — Development Roadmap

**Version:** 0.1 · **Status:** Initial roadmap

## Phase 0 — Pre-production and project foundation
- [x] Existing Unity project identified and audited
- [x] Unity 6.6.10f1 / URP 17.6 / Input System 1.20.1 baseline recorded
- [ ] Project scripts, assets and scenes inspected
- [ ] GDD, TDD, MVP and roadmap maintained
- [ ] Git baseline verified
**Exit gate:** project structure safely reviewed; baseline scene opens.

## Phase 1 — First playable
Player movement/camera; interaction; one UFO; dirt state and spray tool; visible cleaning feedback; job completion and credits.
**Exit gate:** repeatable playable cleaning loop.

## Phase 2 — Core simulation
Job and UFO variations; basic customer arrival/queue; evaluation and rewards; improved cleaning feel/audio/VFX.
**Exit gate:** several job variations without manual scene edits.

## Phase 3 — Facility and progression
Upgrade economy; equipment upgrades; facility expansion; unlock progression.
**Exit gate:** choices visibly change capacity or efficiency.

## Phase 4 — Management and automation
Staff roles/behaviors; assignments; automation and efficiency.
**Exit gate:** meaningful facility management.

## Phase 5 — Content and polish
Art/UI/audio/animation/VFX; profiling and performance budgets; accessibility; save/load; QA.
**Exit gate:** stable content-complete candidate.

## Phase 6 — Release preparation
Windows builds and compatibility tests; store page and marketing assets; optional Android adaptation/device tests; release checklist.
**Exit gate:** release candidate passes QA.

## Working policy
Milestones are estimates, not promises. Scope is reviewed against fun, technical risk, budget and performance. Later-phase systems wait until the MVP loop is validated.
