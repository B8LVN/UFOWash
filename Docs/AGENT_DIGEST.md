# AGENT_DIGEST.md

## One-sentence logline
Inherit a broken wash bay on a twilight alien planet, scrub the galaxy’s strangest ships by hand, and turn their fees into a self-running space-wash empire — without ever losing the satisfaction of the spray.

## Five hooks
- **Grime has a story**: Residue layers reveal ship origins and hide Finds (lost cargo, graffiti, salvage tags).
- **Every outcome is explained**: Forensic Reports show heatmaps and exact reasons for grades, tips, and reputation changes.
- **The Bottleneck Lens**: A toggle names the factor limiting machines, pipes, and workers.
- **Owner’s Touch**: Machines provide consistent volume; only you achieve VIP-grade finishes.
- **A small, dense world**: Four 80m×80m districts that visibly evolve as the company grows.

## Eight agent rules (short form)
1. Document is source of truth; report conflicts.
2. Work on one milestone at a time; no early starts.
3. Status vocabulary: Designed → Source written → Compiles → EditMode tests pass → Play Mode verified → Screenshot verified → Owner accepted.
4. Reports must include: changes, AC status updates, evidence, and issue lists.
5. No standalone builds until owner requests; editor compilation and tests are required.
6. No scope creep; ideas outside current milestone go to Parking Lot (Section 10).
7. Assets: procedural or CC0 (Kenney Space Kit) only; log sources in Docs/ASSET_LOG.md.
8. [TUNE] values must be in ScriptableObject/config files; log all tuning changes.

## Two-Loop Rule
Each loop must feed the other:
- **Hands-on loop** (30s–8min): inspect → pre-rinse → foam → final rinse → report. Tactile, repeatable.
- **Business loop** (5–60min): dispatch → jobs/pricing → build/hire → expand/ survive. Neither dominates.

## Balance guardrails (G1–G5)
- **G1**: No-staff players can unlock Crater Ridge/Ion Flats; Glasswake requires automation + VIP.
- **G2**: Fully automated bays capped at grade B (≤92%); Owner’s Touch exceeds this.
- **G3**: Tier-0 Zorgon Scouts take 6–8min by hand; tiers reduce time but never below 2min.
- **G4**: No pure-number upgrades; each must have visible/behavioral changes in definitions.
- **G5**: Bottleneck shifts: cash → bay time → utilities → staff/routing → reputation/contracts.
