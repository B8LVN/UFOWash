# UFO WASH

Unity 6.6.10f1 · URP 17.6 · C# · PC first, Android later

UFO WASH is a first-person UFO cleaning and business simulation. The player starts with a small wash facility, physically cleans extraterrestrial vehicles, earns credits, upgrades equipment and expands toward an automated interstellar business.

## Current production status
- Phase 0: Pre-production and project foundation
- Unity project exists locally at `C:\\UnityProjects\\UFOWash`
- Local project has not yet been pushed to this repository; repository currently holds production docs only.
- MVP goal: a complete, satisfying cleaning loop in one compact wash bay.
